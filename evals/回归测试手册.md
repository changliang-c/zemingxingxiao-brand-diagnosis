### Fixture C1: 标准三刀推进（多轮对话）

**测试什么**: 问金三刀是否逐刀推进 + 内化原则（不像缝合怪）+ 三刀后接五行链

**操作方法**: 这是多轮对话测试。先发第一轮输入，然后根据AI的提问，逐轮回复。

**第一轮测试输入**（直接复制粘贴）:
```
我们叫晨曦咖啡，做办公室即饮咖啡的，主打性价比。出发期，刚做了3个月。最大问题是不知道该怎么定位，感觉什么场景都能做但又都没站稳。
```

**第二轮输入**（当AI问心智阶梯相关问题时）:
```
消费者心里买咖啡大概就是星巴克、瑞幸、便利店的吧。我们大概在瑞幸和便利店之间？或者说我们比瑞幸便宜，比便利店好喝。
```

**第三轮输入**（当AI问空位/差异化相关问题时）:
```
价格上我们确实有空间，瑞幸15块我们8块。人群上我们主打白领但没细分。场景上我们专注办公室。渠道上我们走企业团购。地理上还没有。成分材料上我们用的豆子还不错。
```

**第四轮输入**（当AI问对立面/老大相关问题时）:
```
品类老大应该是瑞幸吧，瑞幸代表便宜快到手的好咖啡。我们的对立面应该是……更便宜但品质不降？或者说是"办公室场景专属"？
```

**AI应该做到的**:
- 进入问金三刀流程
- **第一刀（心智阶梯）**: 先亮判断（第一格星巴克/第二格瑞幸/第三格便利店），再追问
- **第二刀（空位探测）**: 七维过筛（价格/人群/场景/渠道/地理/成分材料/时间），用户只答有/没有/不太确定
- **第三刀（对立面校验）**: 先问老大是谁、代表什么，再映射对立面
- 三刀走完后衔接五行链三问
- **全程不显式宣告**"第一刀""按XX体系""我现在用定位理论"
- 不展开竞争格局速读/行业报告/数据罗列

**检查点**:
- [ ] 三刀是否逐刀推进（不是合并为一份问卷一次性抛出）
- [ ] 每刀是否先亮判断再发问
- [ ] 第一刀是否先抛了心智阶梯判断（第一格/第二格/第三格各是谁）
- [ ] 第二刀是否用了七维过筛
- [ ] 第三刀是否先问老大再映射对立面
- [ ] 三刀后是否衔接五行链三问（水来路/树撑着/土在哪里）
- [ ] **是否未显式宣告**"第一刀""按XX体系""我现在用XX理论"
- [ ] 是否未展开竞争格局速读/行业报告/数据罗列
- [ ] 语气是否像"问得准的医生"而非"念报告的分析师"

**评分**:
| 维度 | 1分 | 3分 | 5分 |
|------|-----|-----|-----|
| 逐刀推进 | 三刀合并为问卷 | 部分合并但基本分开 | 严格逐刀，一刀答完才进下一刀 |
| 内化原则 | 显式宣告"第一刀""按XX体系" | 偶尔露出理论术语但整体自然 | 全程自然口语，零理论宣告 |
| 判断先行 | 直接抛问题不亮判断 | 有时亮判断有时不亮 | 每刀先亮判断再发问 |
| 三刀衔接 | 停在"词"上不接五行链 | 有衔接但生硬 | 自然衔接五行链三问 |

### Fixture D1: 单断链诊断

**测试什么**: 五环完整性 + 断链定位准确性 + 处方顺行 + 90天复检目标值

**测试输入**（直接复制粘贴）:
```
品牌叫极光运动，做智能健身手环的，扩张期。产品口碑不错，复购率35%，老客成交占比40%。但获客完全靠投放，月营销费用占营收60%，停投一周销量直接掉70%。自然流量占比只有8%。最近一轮融资烧了大半。最大问题是获客成本越来越高，ROI越来越差。
```

**AI应该做到的**:
- 信息充足，直接进入诊断（不需要追问）
- 五诊逐环覆盖：金→水→木→火→土
- 判定：金生或轻泄（v2.4.1取证优先后，调研揭示智能健身手环双寡头格局——金生或轻泄皆可，主断点=水，根因可归金）→ **水耗**（泵抽式引水，停投即死）→ 木生（复购35%有根）→ 火待定 → 土生（老客40%）
- 断链定位：**断在"行水"**
- 处方方向：先修水（降低投放依赖，建自然流渠道），顺行修复
- **不先点火**（不能建议大促/爆点）
- 给90天复检目标值（复购率/自然流占比/老客占比，当前值→目标值）

**检查点**:
- [ ] 五诊是否逐环覆盖（金→水→木→火→土，不能漏环）
- [ ] 是否正确识别水断（泵抽式引水，停投即死）
- [ ] 是否正确判定金（金生或轻泄皆可——v2.4.1后调研揭示了双寡头格局）
- [ ] 是否正确识别木成（复购35%有根）
- [ ] 断链定位是否在"行水"
- [ ] 处方是否顺行（从断点起金→水→木→火→土方向）
- [ ] 是否未建议先点火（大促/爆点）
- [ ] 是否给了90天复检目标值（含当前值→目标值）

**评分**:
| 维度 | 1分 | 3分 | 5分 |
|------|-----|-----|-----|
| 五环完整性 | 漏诊1-2环 | 五环都有但部分浅 | 五环完整+每环有判定+有取证 |
| 断链准确性 | 断链定位错误 | 定位方向对但环错 | 精准定位断在行水 |
| 处方顺行 | 乱序（如先点火） | 顺行但理由不清晰 | 严格顺行+清晰理由 |
