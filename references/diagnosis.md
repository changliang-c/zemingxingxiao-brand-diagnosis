# 择命行效·品牌诊断操作手册

> 执行完整五诊或生成诊断报告时加载本文件。

## 一、五诊五问

咨询全流程对应五环，每环一个核心问句、一份取证清单、一个判定标准、一个常见症。

### 第一诊·问金（下刀诊）
- **话术**："你们不做什么？——说不出来，刀就还没开刃。"
- **取证**：产品线清单、近一年砍掉的业务、创始人口述"我们是谁"。
- **判定**：能在10秒内说清"不做什么"→金成；需要翻PPT→金锈。
- **常见症**：贪症——什么都想做，刀背朝外。

### 第二诊·问水（引水诊）
- **话术**："你的客户是自己流过来的，还是你一桶一桶挑来的？"
- **取证**：流量结构表（自然/付费/转介绍占比）、获客成本趋势、停投一天的数据。
- **判定**：停投后留存>40%→水有落差；<20%→泵抽式引水。
- **常见症**：泵瘾——把挑水当成拥有河流。

### 第三诊·问木（植树诊）
- **话术**："三年前你种的东西，今天哪几棵还在结果？"
- **取证**：SKU生命周期表、供应链自有度、内容资产存量、研发团队归谁。
- **判定**：有可积累、可复用、三年不死的资产→木有根；全靠代工与买量→塑料树。
- **常见症**：叶障——把频繁上新当生长，把换叶子当种树。

### 第四诊·问火（点火诊）
- **话术**："你上一次'爆'，照亮了什么？烧掉了什么？剩下了什么？"
- **取证**：历次大促/事件的前后数据对比、爆后30天留存、峰值与密度的比值。
- **判定**：爆后留存沉淀为正→灶火；爆后一地鸡毛→野火。
- **常见症**：纵火癖——把营销做成连续纵火，靠下一把火掩盖上一把的灰烬。

### 第五诊·问土（归土诊）
- **话术**："停掉所有投放三十天，你的生意还剩几成？"
- **取证**：复购率、老客成交占比、私域规模与活性、口碑/NPS、无投放自然销售额。
- **判定**：自然盘>40%→土厚；<20%→佃农。
- **常见症**：假土——把囤货、压货、一次性人情单当成复购。

## 二、四象判定与处方句式

取证完毕，按水火二气入象。以下话术可直接写进报告：

### 老阳（火旺水滥：声量大、转化虚、烧钱换增长）
**处方句式**："你的问题不是不够响，是太响了。下刀：砍掉X条产品线、X个渠道，把火收到一口灶上。"

### 少阳（火生水蓄：小而美、稳但慢）
**处方句式**："别急着扩品。引水：找一条有势能差的渠道放大现有模型，水宽了再种新树。"

### 少阴（火弱水滞：货好没人知道）
**处方句式**："你是老实人生意。点火：造一个可验证的事件，烧一次密度给市场看，也给团队看。"

### 老阴（火水俱衰：靠惯性活着）
**处方句式**："别点火，会烧死。归土重修：回老客数据里找残金，用老客人群包重新下刀。"

## 三、四象的地形仪器（二次修订增补）

初版四象靠经验入象，修订版给每一象配一组可测量的地形读数，让"象"从手感变成仪器：

- **少阳**（火生水蓄）→ 陡坡下行期：复购带动自然流持续上升，梯度大、方向稳。行动：加大步长。
- **老阳**（火旺水滥）→ 鞍点平台期：声量虚高但增长曲线平躺，投放ROI递减、自然流占比下滑。仪器报"到了"而地形没答应。行动：严禁加火，先下刀减灶。
- **少阴**（火弱水滞）→ 震荡调整期：数据方向频繁反转，波动不是死亡信号，是地形在重新定向。行动：减小步长、加密观察。
- **老阴**（火水俱衰）→ 收敛蛰伏期：各项读数双双趋稳，可榨取性耗尽。行动：唯一正确的动作是归土重修，回老客数据里找残金。

手感是师父的，仪器是徒弟的；仪器配齐，这套诊断才能离开创立者本人独立行走。

## 四、处方禁忌三条

1. 不给超出客户执行力的方——药方开给活人，不开给标本。
2. 不动客户的土去做火——烧用户资产换GMV的建议，是咨询师的渎职。
3. 不承诺火的时辰——可以承诺链条修复顺序，不承诺"三个月必爆"。承诺爆发的是骗子。

## 五、可交付报告模板（一页骨架）

```
《XX品牌 择命行效·五行诊断报告》

〇、三句话结论（入象 + 断链环 + 处方方向）

一、问金：下刀诊 → 现状 / 判定 / 金之方
二、问水：引水诊 → 现状 / 判定 / 水之方
三、问木：植树诊 → 现状 / 判定 / 木之方
四、问火：点火诊 → 现状 / 判定 / 火之方
五、问土：归土诊 → 现状 / 判定 / 土之方

六、四象判定：___象，依据：___

七、修复顺序：第1环→第2环→第3环（严禁乱序）

八、验收标准：90天后复检，以「土指标」三件套验收：
    复购率 / 自然流占比 / 老客成交占比

九、免责与边界：本报告不修命，只修链。
```

模板里有两个设计心机：
- 第七节"修复顺序"是灵魂：链条必须从断点修起，且只能顺行（金→水→木→火→土）。客户最常犯的错就是想先点火——报告的权威感，就立在敢说"不，先修你的木"。
- 第八节把"效必归土"变成验收条款——这是这套咨询体系敢收钱的根本：验收指标写在合同里，拒绝假大空从约束自己开始。

## 六、验收标准

咨询效果以"客户土变厚了没有"验收，不以PPT页数验收。90天后复检，只看三个土指标：
1. **复购率**
2. **自然流占比**
3. **老客成交占比**

## 七、开场与收尾话术

**开场（破冰定调）**：
"我不给你做品牌升级，也不给你讲定位。我就干一件事：给你的生意做一次体检，查出你的链条断在哪一环。断在金，省钱；断在土，救命。"

**收尾（归土式跟进）**：
"报告交付不是结束，是这一轮循环的归土。90天后我回来复检，只看你三个土指标。土厚了，我们再谈下一轮下刀——因为上一轮的土，就是你下一轮的金。"

这句话同时是商业模式：复检即复购，循环即续费。理论自洽到收费结构上，才叫体系。

## 八、三条交付铁律

从理论铁律直译：
1. **行在知前** → 没有实地走访与数据取证，不出报告。坐而论道的咨询是诈骗。
2. **循环不息** → 报告必须给出闭环处方，禁止只诊断不开方。
3. **效必归土** → 咨询效果以"客户土变厚了没有"验收，不以PPT页数验收。

## 九、治未病体检单（季度自检工具）

> 这张单子每季度填一次，半小时够了。数据从报表里抄，别凭感觉填。
> 中医讲治未病，靠的是脉象；企业也一样，脉象就是这些数。
> 哪一格碰了预警线，当季就处理，拖一个季度，小病变大病。
> 填的时候对自己诚实，体检单骗自己，比不体检还贵。

**企业名称**：＿＿＿＿＿＿＿＿　**填表人**：＿＿＿＿＿＿　**日期**：＿＿＿＿年＿＿月＿＿日

**企业在哪个阶段**：□ 出发点（还没开张或刚开张）　□ 搭建（在搭团队和产品）　□ 商业模式（在验证赚不赚钱）　□ 扩张（已经长大，毛病不致命）

### 一、问金（下刀诊）——查的是取舍

1. 现在有几条产品线？＿＿＿条。去年同期是＿＿＿条。
2. 过去一年砍掉了什么业务？＿＿＿个。写出来：＿＿＿＿＿＿＿＿＿＿＿＿
3. 新品动销率：＿＿＿%
4. "你们不做什么？"能不能10秒内说出口？□ 能　□ 不能

**预警线**（碰到任意一条就算）：一年下来一个业务都没舍得砍；新品类增速连续两年跑赢营收增速；"不做什么"要翻PPT才答得上。
**怎么处理**：当季只做减法。把占着资源不产出的产品砍掉，把"不做什么"写下来，贴在开会看得见的地方。

### 二、问水（引水诊）——查的是流量来路

1. 客户怎么来的：自然来＿＿＿%　／　花钱买＿＿＿%　／　老客介绍＿＿＿%
2. 获客成本：本季＿＿＿元，去年同期＿＿＿元
3. 停投测试：停掉所有投放一周，销量还剩＿＿＿%

**预警线**：停投后剩不到两成，说明你在挑水，不在引水；获客成本的涨幅连续超过客单价的涨幅；付费流量占比一年比一年高。
**怎么处理**：先别加投放。回头找一条有势能差的渠道，把自然流养起来。挑水不丢人，把挑水当成拥有河流才丢人。

### 三、问木（植树诊）——查的是根在不在自己手里

1. 三年前种下的东西，今天还在结果的有几个？写名字：＿＿＿＿＿＿＿＿
2. 供应链：自有＿＿＿%　／　代工＿＿＿%
3. 研发投入占营收：＿＿＿%

**预警线**：三年前的产品一个都没活下来；全靠代工，上新等于换包装；新品动销率不到三成。
**怎么处理**：停掉无效上新。钱和人集中给一棵能活三年的树，别同时种十棵速生杨。

### 四、问火（点火诊）——查的是爆发之后剩下什么

1. 上一次"爆"是什么时候？＿＿＿＿＿＿
2. 爆后30天，冲进来的新客留下了＿＿＿%
3. 那场火照亮了什么？＿＿＿＿＿＿＿＿。剩下了什么？＿＿＿＿＿＿＿＿

**预警线**：爆完只剩一地鸡毛；得靠下一把火来遮上一把的灰。
**怎么处理**：爆后留存是负的，下一季不许再点火。回去修木和土。断环点火，是这五条里最贵的一个动作。

### 五、问土（归土诊）——查的是沉淀，也是总账

1. 复购率：＿＿＿%
2. 老客成交占比：＿＿＿%
3. 不做任何投放的自然销售占比：＿＿＿%

**预警线**：自然盘不到两成，你是佃农，地在别人手里；把囤货、压货、预付费、人情单算成了复购。
**怎么处理**：土指标是整张单子里唯一不许粉饰的数。假土比没土危险，没土你知道慌，假土让你以为稳。

### 判定区

**先看水火，定个象：**
- 声量大、转化虚、烧钱换增长 → **老阳**。你的问题不是不够响，是太响了。砍灶，别加柴。
- 小而美、稳但慢 → **少阳**。别急着扩品，先把水渠挖宽。
- 货好没人知道 → **少阴**。造一个可验证的事件，烧一次密度给市场看。
- 靠惯性活着 → **老阴**。别点火，会烧死。回老客数据里找残金，用老客人群重新下刀。

**断链定位**：这次体检，最先碰预警线的是第＿＿项（金／水／木／火／土）。它就是断链处。

**修复顺序**：从断的那一环修起，只能顺着金、水、木、火、土往下走，不许跳。客户最常犯的错是想先点火，你敢说"不，先修你的木"，这张单子才算没白填。
