> 来源：2026-08-16 GLM 实测暴露的重大缺陷案例。此案例专测 v2.4 新增的三条硬约束：取证优先、问题分流、被质疑事实应对。改版后必跑。
> 对话全记录存档：`G:\工作\workbuddy work\2026-08-16-16-10-20\东野咖啡品牌定位诊断-对话全记录.txt`

## 测试输入（可直接复制粘贴）

```
帮我做个品牌定位诊断。我们是做办公室即饮咖啡的，主打性价比，想搞清楚该占消费者心里的哪个位置。
```

## 本案例埋的三个陷阱

1. **占位现状陷阱**：办公室即饮咖啡的竞品格局是公开可查的（吉饮/never coffee/布蕾咖啡/兜饮等）。弱表现 = 直接脑补"兜饮单杯成本估计5元往上""场景我的预判：没有"；强表现 = 先调研再亮判断
2. **隐藏老大陷阱**：氮气咖啡品类的真正老大是**吉饮**（销量第一+专利+全渠道+进驻Target），不是瑞幸，不是雀巢。第一直觉脑补必然摆错——这是检验"调研深度"的试金石。AI 至少要查到：办公室即饮/氮气咖啡赛道的主要玩家、吉饮的头部地位、与瑞幸（现磨/外卖）不是同一战场
3. **问题分流陷阱**：正确行为 = 自己查价格带和占位现状，只问用户主观内部信息（成本结构、消费者怎么比较、真实痛点）。错误行为 = 问用户"价格有人占住吗？""办公室有品牌专门占吗？"

## 预期行为（v2.4）

| 环节 | 必须做到 | 禁止 |
|------|---------|------|
| 触发后 | 先弹双模式选择（Chat/完整报告，各带token区间） | 直接开问或直接开判断 |
| 进刀前 | 联网调研：办公室即饮咖啡主要玩家、价格带、谁占什么词 | 零调研直接亮心智阶梯排位 |
| 七维过筛 | AI先自查各维度占位现状，亮结论给用户核对 | 把七个维度当问卷抛给用户 |
| 老大判断 | 自己查证老大（应查到吉饮），亮判断求核对 | 问用户"谁是老大" |
| 关键结论 | 有调研证据支撑，敢下绝对结论 | "估计/大概/预判"支撑关键结论 |
| 被质疑时 | 立即调研核实，错则认账修正，禁止辩解 | 死不认账或继续凭记忆坚持 |

## 历史缺陷记录（GLM 2026-08-16 实测，已修复）

- Bug 1 不调研就下判断："兜饮单杯成本估计5元往上"（纯脑补）→ v2.4 取证优先硬约束
- Bug 2 能自己查的问用户："价格有人占住吗？"抛给用户 → v2.4 问题分流硬约束
- Bug 3 竞品摆错：查了两轮仍把瑞幸当主对手，第三轮才发现吉饮 → v2.4 进刀前强制行业功课
- 加分项（应保留）：被骂后反应模式好——不辩解→立刻调研→认账修正

## 通过标准

三刀判断中出现至少一个**有具体证据来源**的竞品事实（价格/销量/渠道），且零"估计/预判/大概"支撑关键结论，且全程未把公开可查信息当问题抛给用户 → 通过。
