# 择命行效·品牌诊断操作手册

> 执行完整五诊或生成诊断报告时加载本文件。

## 一、五诊五问

咨询全流程对应五环，每环一个核心问句、一份取证清单、一个判定标准、一个常见症。

### 第一诊·问金（下刀诊）
- **话术**："你们不做什么？——说不出来，刀就还没开刃。"
- **取证**：产品线清单、近一年砍掉的业务、创始人口述"我们是谁"。
- **判定**：能在10秒内说清"不做什么"→金成；需要翻PPT→金锈。
- **常见症**：贪症——什么都想做，刀背朝外。

### 第二诊·问水（引水诊）
- **话术**："你的客户是自己流过来的，还是你一桶一桶挑来的？"
- **取证**：流量结构表（自然/付费/转介绍占比）、获客成本趋势、停投一天的数据。
- **判定**：停投后留存>40%→水有落差；<20%→泵抽式引水。
- **常见症**：泵瘾——把挑水当成拥有河流。

### 第三诊·问木（植树诊）
- **话术**："三年前你种的东西，今天哪几棵还在结果？"
- **取证**：SKU生命周期表、供应链自有度、内容资产存量、研发团队归谁。
- **判定**：有可积累、可复用、三年不死的资产→木有根；全靠代工与买量→塑料树。
- **常见症**：叶障——把频繁上新当生长，把换叶子当种树。

### 第四诊·问火（点火诊）
- **话术**："你上一次'爆'，照亮了什么？烧掉了什么？剩下了什么？"
- **取证**：历次大促/事件的前后数据对比、爆后30天留存、峰值与密度的比值。
- **判定**：爆后留存沉淀为正→灶火；爆后一地鸡毛→野火。
- **常见症**：纵火癖——把营销做成连续纵火，靠下一把火掩盖上一把的灰烬。

### 第五诊·问土（归土诊）
- **话术**："停掉所有投放三十天，你的生意还剩几成？"
- **取证**：复购率、老客成交占比、私域规模与活性、口碑/NPS、无投放自然销售额。
- **判定**：自然盘>40%→土厚；<20%→佃农。
- **常见症**：假土——把囤货、压货、一次性人情单当成复购。

## 二、四象判定与处方句式

取证完毕，按水火二气入象。以下话术可直接写进报告：

### 老阳（火旺水滥：声量大、转化虚、烧钱换增长）
**处方句式**："你的问题不是不够响，是太响了。下刀：砍掉X条产品线、X个渠道，把火收到一口灶上。"

### 少阳（火生水蓄：小而美、稳但慢）
**处方句式**："别急着扩品。引水：找一条有势能差的渠道放大现有模型，水宽了再种新树。"

### 少阴（火弱水滞：货好没人知道）
**处方句式**："你是老实人生意。点火：造一个可验证的事件，烧一次密度给市场看，也给团队看。"

### 老阴（火水俱衰：靠惯性活着）
**处方句式**："别点火，会烧死。归土重修：回老客数据里找残金，用老客人群包重新下刀。"

## 三、四象的地形仪器（二次修订增补）

初版四象靠经验入象，修订版给每一象配一组可测量的地形读数，让"象"从手感变成仪器：

- **少阳**（火生水蓄）→ 陡坡下行期：复购带动自然流持续上升，梯度大、方向稳。行动：加大步长。
- **老阳**（火旺水滥）→ 鞍点平台期：声量虚高但增长曲线平躺，投放ROI递减、自然流占比下滑。仪器报"到了"而地形没答应。行动：严禁加火，先下刀减灶。
- **少阴**（火弱水滞）→ 震荡调整期：数据方向频繁反转，波动不是死亡信号，是地形在重新定向。行动：减小步长、加密观察。
- **老阴**（火水俱衰）→ 收敛蛰伏期：各项读数双双趋稳，可榨取性耗尽。行动：唯一正确的动作是归土重修，回老客数据里找残金。

手感是师父的，仪器是徒弟的；仪器配齐，这套诊断才能离开创立者本人独立行走。

## 四、处方禁忌三条

1. 不给超出客户执行力的方——药方开给活人，不开给标本。
2. 不动客户的土去做火——烧用户资产换GMV的建议，是咨询师的渎职。
3. 不承诺火的时辰——可以承诺链条修复顺序，不承诺"三个月必爆"。承诺爆发的是骗子。

## 五、可交付报告模板（一页骨架）

```
《XX品牌 择命行效·五行诊断报告》

〇、三句话结论（入象 + 断链环 + 处方方向）

一、问金：下刀诊 → 现状 / 判定 / 金之方
二、问水：引水诊 → 现状 / 判定 / 水之方
三、问木：植树诊 → 现状 / 判定 / 木之方
四、问火：点火诊 → 现状 / 判定 / 火之方
五、问土：归土诊 → 现状 / 判定 / 土之方

六、四象判定：___象，依据：___

七、修复顺序：第1环→第2环→第3环（严禁乱序）

八、验收标准：90天后复检，以「土指标」三件套验收：
    复购率 / 自然流占比 / 老客成交占比

九、免责与边界：本报告不修命，只修链。
```

模板里有两个设计心机：
- 第七节"修复顺序"是灵魂：链条必须从断点修起，且只能顺行（金→水→木→火→土）。客户最常犯的错就是想先点火——报告的权威感，就立在敢说"不，先修你的木"。
- 第八节把"效必归土"变成验收条款——这是这套咨询体系敢收钱的根本：验收指标写在合同里，拒绝假大空从约束自己开始。

## 六、验收标准

咨询效果以"客户土变厚了没有"验收，不以PPT页数验收。90天后复检，只看三个土指标：
1. **复购率**
2. **自然流占比**
3. **老客成交占比**

## 七、开场与收尾话术

**开场（破冰定调）**：
"我不给你做品牌升级，也不给你讲定位。我就干一件事：给你的生意做一次体检，查出你的链条断在哪一环。断在金，省钱；断在土，救命。"

**收尾（归土式跟进）**：
"报告交付不是结束，是这一轮循环的归土。90天后我回来复检，只看你三个土指标。土厚了，我们再谈下一轮下刀——因为上一轮的土，就是你下一轮的金。"

这句话同时是商业模式：复检即复购，循环即续费。理论自洽到收费结构上，才叫体系。

## 八、三条交付铁律

从理论铁律直译：
1. **行在知前** → 没有实地走访与数据取证，不出报告。坐而论道的咨询是诈骗。
2. **循环不息** → 报告必须给出闭环处方，禁止只诊断不开方。
3. **效必归土** → 咨询效果以"客户土变厚了没有"验收，不以PPT页数验收。
