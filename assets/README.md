## 自动替换信息功能

**核心特性**：本目录的配图配合 `references/visual_templates.md` 中的 SVG 动态模板使用。AI 在生成报告时，根据用户品牌的实际数据动态填充图表中的信息位，不使用固定占位文字。

**填充规则**：
1. 配图作为静态视觉模板，提供理论框架的视觉规范
2. SVG 模板（见 visual_templates.md）提供动态生成的图表代码
3. AI 在报告中**双管齐下**：引用配图展示理论框架 + 动态生成 SVG 展示品牌具体数据
4. 配图中的文字说明与 SVG 中的数据必须一致

**举例**：
- 报告「五行链条诊断」章节：先引用 `02_五行行动链循环图.png` 展示理论框架，再用 SVG 动态生成「五行链条诊断图」展示用户品牌的五环状态（成/锈/断）
- 报告「四象判定」章节：先引用 `05_四象地形状态图.png` 展示四象地形，再用 SVG 动态生成「四象定位图」标注用户品牌在坐标系中的位置 + 对照案例位置
